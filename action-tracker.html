🟢 Connect Supabase

One-time setup — 4 steps, about 3 minutes. No Google account needed.
1
Go to supabase.com → Start your project → sign up free (use any email)
2
Click New project → enter name action-tracker → set a DB password → click Create new project → wait ~1 min for it to load
3
Go to SQL Editor (left sidebar) → paste this and click Run:
create table tracker (id int primary key, data text, comms text);
insert into tracker values (1, '[]', '[]');
4
Go to Project Settings → API → copy the Project URL and the anon / public key → paste below
🔒 Keys are saved in your browser only — never shared with anyone else.
